## ADDED Requirements

### Requirement: 하단 트렌딩 뉴스 리스트 표시

메인 페이지의 하단 영역에 현재 가장 이슈가 되고 있는 트렌딩 뉴스를 리스트 형태로 제공해야 한다.

#### Scenario: 뉴스 피드 확인

- **WHEN** 사용자가 메인 페이지의 하단으로 스크롤할 때
- **THEN** 최신 트렌딩 뉴스의 제목, 요약, 시간 등을 포함한 리스트가 표시된다.

### Requirement: 뉴스 원문 링크 연결

각 뉴스 항목을 클릭하면 해당 뉴스의 원문 페이지로 이동할 수 있어야 한다.

#### Scenario: 뉴스 항목 클릭

- **WHEN** 사용자가 특정 뉴스 항목을 클릭할 때
- **THEN** 브라우저가 새 탭(또는 현재 창)에서 해당 뉴스의 원문 URL로 이동한다.

### Requirement: 뉴스별 영향을 미치는 코인 태그 표시

각 뉴스 항목에는 해당 뉴스와 관련된 코인 심볼이나 이름이 태그 형태로 표시되어야 한다.

#### Scenario: 코인 태그가 포함된 뉴스 렌더링

- **WHEN** 뉴스 데이터에 연관된 코인 정보가 있을 때
- **THEN** 뉴스 제목 하단 또는 옆에 해당 코인(예: BTC, ETH)의 태그가 표시된다.
