## ADDED Requirements

### Requirement: 종목 섹터별 리스트 표시

메인 페이지에서 코인의 목록을 4가지 섹터(24시간 최고거래량, 최고가격상승, 최고가격하락, 새롭게 출시된 코인)로 분리하여 세로 리스트 형태로 제공해야 한다.

#### Scenario: 메인 페이지 접속 시 섹터별 데이터 로딩

- **WHEN** 사용자가 메인 페이지에 접속할 때
- **THEN** 시스템은 4가지 섹터의 코인 목록 데이터를 불러와 각각의 리스트로 렌더링한다.

### Requirement: 섹터별 정렬 기능

각 섹터 내의 코인 리스트는 오름차순(ASC)과 내림차순(DESC)으로 정렬할 수 있어야 한다.

#### Scenario: 정렬 버튼 클릭

- **WHEN** 사용자가 특정 섹터 리스트의 헤더(가격, 등락률 등)를 클릭할 때
- **THEN** 리스트는 해당 기준에 따라 오름차순/내림차순으로 전환되어 정렬된 결과를 표시한다.

### Requirement: 값의 범위에 따른 동적 텍스트 색상 적용

사용자가 시장 상황을 쉽게 파악할 수 있도록, 등락률이나 가격 등 값의 범위에 따라 텍스트 색상이 다르게 표시되어야 한다. (예: 상승은 초록색/빨간색, 하락은 빨간색/파란색 등 명확한 대비)

#### Scenario: 양수/음수 데이터 렌더링

- **WHEN** 데이터의 등락률이 양수일 때
- **THEN** 해당 텍스트를 상승을 의미하는 색상으로 렌더링한다.
- **WHEN** 데이터의 등락률이 음수일 때
- **THEN** 해당 텍스트를 하락을 의미하는 색상으로 렌더링한다.
