## ADDED Requirements

### Requirement: 대시보드 라우팅 및 뷰 제공

사용자가 `/dashboard` 경로로 접속 시 개인 투자 현황을 파악할 수 있는 대시보드 페이지를 제공해야 한다.

#### Scenario: 대시보드 페이지 접근

- **WHEN** 사용자가 내비게이션 바에서 "Dashboard" 링크를 클릭하거나 `/dashboard`로 직접 접속할 때
- **THEN** 사용자의 투자 현황(총 자산, 평가 손익 등)을 나타내는 요약 카드와 리스트가 포함된 대시보드 레이아웃이 렌더링된다.

### Requirement: 투자 현황 파악 기능

대시보드에서는 사용자의 자산, 수익률 등 주요 지표를 보여주어야 한다. (초기 단계에서는 목 데이터 기반)

#### Scenario: 목업 데이터 기반 포트폴리오 렌더링

- **WHEN** 대시보드가 로딩되었을 때
- **THEN** 현재 사용자의 보유 자산(보유 코인, 평가액, 수익률) 정보를 테이블 또는 카드 형태로 표시한다.
